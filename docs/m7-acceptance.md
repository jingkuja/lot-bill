# M7：首版试用验收

日期：2026-10-01（Asia/Shanghai）。版本：0.1.0（1）。本轮使用合成数据，真实账单与真实 AI 服务未参与测试。

## 安装与试用

本机签名配置放在被忽略的 `Config/Local.xcconfig`。保持相同 Bundle ID 和签名团队安装可保留应用容器；不要为更新卸载 App。

```bash
xcrun devicectl list devices
bash scripts/install-device.sh <DEVICE_UDID>
```

脚本构建 Release 版本、签名、安装并启动。Release 安装包不包含独立验收账本、模拟 AI、合成文件或中断注入入口。验收产生的 `M7-<UUID>` 文件夹及 `M7-Roundtrip-<UUID>` 导出文件可能仍留在本机 Documents 中，可在“文件”App 内按名称识别并自行清理；这些文件不会自动导入正常账本。首次使用可能需要在 iPhone 的“设置 → 通用 → VPN 与设备管理”信任开发者证书；本次签名配置到期时间为 2026-10-08 13:19（Asia/Shanghai），到期后重新运行安装脚本。测试入口为 `scripts/test-device.sh`，测试期间保持解锁，避免手动切换页面。

## 本地备份的完整操作

1. 设置 → 备份与恢复 → 生成并导出完整备份。
2. 在系统文件界面选择本机的 Lot Bill 文件夹或其他自选位置，确认存储。只有 Documents 文件夹对“文件”App 可见，数据库、Keychain 和本机恢复点不在该公开目录中。
3. 设置 → 备份与恢复 → 选择备份文件，选择刚才导出的 JSON。
4. 核对条数、时间和来源，点击确认整体恢复。此操作替换账本，先自动保存原账本恢复点。
5. 恢复后返回首页检查金额；需要撤回时，从“本机恢复点”读取对应文件，再确认恢复。

本机 Lot Bill 文件夹和恢复点都会随卸载 App 丢失。长期备份请另存到用户选择的独立位置。CSV 只用于表格查看，不能替代完整 JSON 备份。

## 验收方法

- 独立 UUID 测试数据库与 AI 配置作用域，正常 `Ledger-v1.store` 不注入合成交易。
- 系统文件场景使用单独的 `Documents/M7-<UUID>` 文件夹。DEBUG 准备合成历史 CSV，随后由系统选择器、正式解析器及正式导出/恢复入口完成操作。
- 万条性能测试使用磁盘 SwiftData 容器，验证条数和精确总额，分别计时搜索、统计、CSV、逻辑备份编码/解码、批量恢复、已有万条流水时的历史导入与重新打开。
- 恢复中断在全部内存变更完成、数据库提交前，以及提交并重新加载后调用 `_exit(0)`，不运行应用生命周期收尾；重开验证整份旧账本或新账本，以及原账本恢复点。此实验不能替代断电或正在写磁盘时的故障试验。
- UI 检查覆盖常规浅色、深色最大辅助字号、金额和备注输入、日期选择、长列表滚动和搜索。大字体/深色仅覆盖测试应用内容，不修改用户全局系统设置。

## 明确限制

- 最低部署目标 iOS 18；当前本机仅安装 iOS 27.0 runtime，最低版本运行兼容性未验证，不把编译成功等同于该版本运行通过。
- 未提供有金额的真实历史账单、月末真实样本或真实 AI 供应商配置。合成场景通过不代表真实迁移和供应商协议兼容已通过。
- 一万条是本轮验收规模；当前仓储仍把数据载入内存，未承诺十万条同等体验。CSV/XLSX 入口导入分类汇总，不支持逐笔支付平台明细；一万条批量交易验收通过逻辑备份恢复实现。
- 不执行物理断电试验；数据库写入中途断电及存储硬件故障未覆盖。
- 金额/备注的聚焦、输入、收起与保存已验证；自动化截图未显示屏幕软键盘，不能据此判定所有系统/第三方键盘遮挡组合均通过。
- 分类手动排序、最近账户记忆为后续体验改进；当前使用开发版默认图标。
- 本次交付为个人签名试用版本，不包含 TestFlight、App Store 提交或商店审核。

## 执行结果

### 已取得的证据

- 模拟器：iPhone 18 Pro / iOS 27.0（24A434），万条磁盘测试通过；中断恢复和长列表通过；最终文件全流程及深色最大字号复测 2/2 通过，runtimeWarnings 为空。
- 真机：iPhone 18 Pro Max / iOS 27.0（24A437），51 项领域/持久化/性能测试、13 项 UI 场景分别取得通过结果。首次完整运行 62/64 通过，两项 UI 交互失败；修正确认按钮等待和系统目录返回后，最终定向复测 4/4 通过（包括这两项、普通流水搜索、万条长列表），runtimeWarnings 为空。没有把首次完整运行写成全通过。
- 模拟器系统实际导出的 JSON 和 CSV 已由独立 Python JSON/CSV 读取器核对：流水 1 条、1200.00 元；历史汇总 2 条；有效调整 150.00 元。恢复前人为增加 10 元，恢复后及重启后均回到 1350.00 元。
- 保存后的独立万条账本经 SIGKILL 结束进程，再以同一作用域重启且不传入造数参数，首页合计仍为 10100.00 元；提交前/后异常退出与恢复点另有 UI 断言。
- Release 0.1.0（1）已通过安装脚本安装到真机，正常启动为正式空账本，合成流水未进入正常账本。
- Release 构建通过；安装包包含文件共享布尔配置、最低部署目标 18.0，二进制不包含 DEBUG 测试参数。应用源码无账单正文或密钥日志调用；本轮真机控制台未出现测试密钥/隐私哨兵。UI 测试附件本身含合成业务数据，真实使用时不要直接外传诊断包。

### 本轮修正

- 文件共享开关改为显式 `Info.plist`，解决自动生成配置未写入导致“我的 iPhone”下无 Lot Bill 文件夹的问题。
- 辅助字号的流水卡片改为纵向排列，金额保持一行，解决金额拆行和账户文字被挤窄。
- 流水页每次渲染只筛选并按日分组一次，消除每个日期分区反复全量筛选的问题。
- 增加 `scripts/install-device.sh`，构建并安装个人签名 Release 版本；真机测试脚本关闭额外系统诊断采集，保留测试日志和结果附件。
- 增加万条磁盘测试、真实文件往返、最大字号编辑、恢复提交前后退出及恢复点验证。

### 环境排障

初次运行分别遇到锁屏、证书未信任和 XCTest 连接前退出 code 74。用户解锁、信任证书、改有线并重启后，code 74 仍存在；重建 Mac 当前用户的 CoreDeviceService 会话后，最小真机测试通过，随后业务测试正常执行。早期失败/未执行的结果不计为通过。
