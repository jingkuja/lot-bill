# 合成开发样本

本目录只包含人为构造的数据，不代表用户的实际收支。

- `history.json`：第一分类年度合计，2025 年覆盖全年、2026 年截至 8 月底；包含空白与明确零值。金额以分表示。
- `daily.json`：同一月份的日常分类记录，餐饮合计 1,200 元、交通合计 400 元。
- `monthly.json`：月末对账依据，餐饮 1,350 元、交通 400 元，餐饮待核对差额为 150 元。
- `categories.json`：用户模板中的分类名称，不包含个人金额、账户或身份信息。

`history.csv`、`reconciliation.csv` 是可直接导入的合成分类汇总文件。XLSX 边界、共享字符串、合并与公式缓存样例由 `TabularFileTests.workbook` 动态生成。

这些 JSON 是领域样例，不属于文件导入格式。不得将 `null` 当作零，不得将区间合计拆成逐笔交易；真实数据不要存入此目录。
